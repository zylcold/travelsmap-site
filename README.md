## 是什么

选择多张旅行照片，应用会按拍摄位置把它们标记到地图上，形成属于你的旅行轨迹图。支持通过 iCloud 在 iPhone、iPad、Mac、Apple Watch 之间同步。

## 核心功能

- **地图标记**：照片按地理位置自动落点，一眼看到去过哪里
- **批量选择**：一次导入多张旅行照片
- **多设备同步**：通过 iCloud 在 iOS / iPadOS / macOS / watchOS 间同步
- **动态字号与深色模式**：完整支持动态字体、深色外观、减弱动效与触感反馈（1.5.6+）
- **内购解锁**：一次性购买或订阅解锁高级能力
